# Python Wizardry

A small installable web app (PWA) that tracks a path through ten levels of Python, with a daily streak.

- Stones (skills) are marked done by editing `DONE` in `index.html` when the skill is shown by writing the code.
- The streak is stored in the browser (`localStorage`), so it stays on the device you log it from.
- Open it over HTTPS (GitHub Pages) and use "Add to Home screen" to install.
